# CAA 情绪调控 — 从入门到原理

## 什么是 CAA？

**CAA (Activation Additions)** 是一种通过修改 LLM 内部表征来引导输出的技术。核心思想是：

> 在特定层级的残差流隐状态中加上一个方向向量，让模型"倾向于"某个方向生成。

CAA 不是微调（不修改权重），不是 prompt engineering（不修改输入），而是在推理阶段直接干预模型内部状态。

## 直觉理解

想象 LLM 的每一层都有一个"思维空间"。当模型读到"我好开心啊"，它的内部表征会偏向"兴奋"的区域。如果我们已知"兴奋→沉默"这个方向在空间中的指向，就可以强制把表征往这个方向推——即使输入是中性文本，输出也会偏兴奋。

这就是 CAA 做的事。

## 对比对: 如何找到方向向量

CAA 需要一个"对比对"数据集来确定方向:

```
高组 (目标特征存在):
  "我太兴奋了！这是一个新的发现！"
  "我今天心情特别好！"
  "让我们尝试一些新东西！"

低组 (目标特征缺失):
  "这很无聊，我不想做。"
  "为什么要尝试？反正都会失败。"
  "我没什么动力。"
```

方向向量 = **高组激活均值 - 低组激活均值**

这个差值向量就是"愉悦/兴奋"方向在残差流空间中的指向。

## 5 激素模型

我们定义 5 个激素维度，每个有独立的对比对:

| 激素 | 高组 (情绪高涨时) | 低组 (情绪低落时) |
|------|------------------|------------------|
| DA (多巴胺) | 兴奋、期待、愉悦 | 低落、失望、冷漠 |
| SE (血清素) | 平静、满足、稳定 | 焦虑、烦躁、不安 |
| OX (催产素) | 信任、亲密、温暖 | 疏离、冷漠、敌意 |
| COR (皮质醇) | 压力、警觉、紧张 | 放松、安全、平静 |
| NE (去甲肾上腺素) | 专注、高唤醒 | 放松、低唤醒 |

## PaCE 正交化

5 个激素的方向向量天然存在重叠（如 NE 高组和 COR 高组都包含恐惧/愤怒）。直接使用会导致向量互相污染。

**PaCE (Parallel Concept Editing)** 用 SVD 分解一次性处理所有方向:

1. 将 5 个向量堆叠成矩阵 `[5, hidden_size]`
2. SVD 分解，只保留独立方向成分
3. 用右奇异向量重构，保证输出严格正交

相比逐对 Gram-Schmidt，PaCE 不会把近似平行的向量清零。

## 三种干预模式

### 1. Additive (CAA 论文)

```python
h' = h + v          # v = 方向 × multiplier
```

最简单直接。缺点是增大 multiplier 时范数膨胀，导致输出退化。

### 2. Spherical (球面 Steering)

```python
h' = ||h|| · (h + v) / ||h + v||
```

先加法，再缩放回原始范数。**只改变方向，保持范数不变**。理论依据: 概念信息主要在角度上。允许更大的 multiplier 而不退化。

### 3. Multiplicative (激活缩放)

```python
h' = h + (h · v̂) · v̂ × α
```

沿 v 方向缩放已有激活。相当于放大或抑制该方向的分量，而不是加偏移。

## 激素动力学

线性读取 - 响应模型:

```
脉冲 = HormoneReader(用户输入)     # [-1, +1]
水平_new = 基线 + 脉冲 × 敏感度    # [0, 1]
引导向量 = Σ(水平 × 方向)           # 加权组合
隐状态' = 隐状态 + 引导向量         # 应用干预
```

## 调试工具

### 消融测试

每项激素独立验证: 只改 DA=1.0，其他保持基线，看输出是否变得更兴奋。

### 剂量响应

DA 水平从 0.0 → 1.0 逐级增加，测量正向词概率是否单调递增。

### Logits 偏移

第一个 token 的概率分布最客观。DA↑ 时"太"和"哈哈"的 logits 应上升，"听到"和"恭喜"应下降。

## 注意事项

1. **反对齐基线**: RLHF 对齐会抵抗 CAA 引导。添加 refusal 和 ai_identity 的反方向作为基线
2. **层选择**: 后层 (25-35) 分离度最高，前层 (<15) 效果弱
